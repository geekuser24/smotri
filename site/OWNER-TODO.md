# Что осталось передать для smotri.cc

## Архивы приватных паков

Можно передать папку на ноутбуке или ссылки на скачивание. Нужны оригинальные файлы, которые можно бесплатно распространять:

- [x] Vertical Pack — ZIP загружен на сервер, SHA-256 и скачивание через сайт проверены.
- [x] Premier Pack | Pr Pro — оригинальный .prfpset загружен на сервер.
- [x] CC EDIT PACK + FLICKER + RAW SCENES — исходный ZIP загружен на сервер.
- [x] VIDEO MAKER COLLECTION PACK vol.1 — пять частей объединены в один ZIP (9 249 661 534 байта); 1 640 записей проверены по SHA-256. Файл размещён на сервере и привязан к карточке.
- [x] SFX BANK — ZIP скачан с Google Drive на сервер, целостность проверена.

Обложки и описания уже найдены в Geek MP4 Bot. Все перечисленные паки загружены на сервер и доступны после проверки условий скачивания.

## Проверка запуска

- [x] DNS smotri.cc и www.smotri.cc настроены на сервер.
- [x] SSH-доступ к серверу найден через PEM-ключ.
- [x] Домен smotri.cc указан для @Geekmp4_bot в BotFather — подтверждено владельцем.
- [ ] Проверить вход через свой Telegram и получение пака после подписки.
