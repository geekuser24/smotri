# Изменения Smotri

## 0.12.0 preview.20261026.6

- Complete Linux ARM64 VST3 ABI compatibility for plugin class identifiers. Includes all timeline, effect clipboard and audio-plugin updates described below.

## 0.12.0 preview.20261026.5

- Regular edge drags trim all selected clips together, including unlinked video/audio. Media handles and neighbours constrain the common delta; one Undo restores the group.
- Files dropped from Finder/Explorer onto an occupied timeline use a free track, creating one when necessary. Empty timelines still create a sequence automatically.
- Clicking a clip's FX badge selects it and opens Effect Controls.
- Copy a selected Effect Controls section with Cmd/Ctrl+C and paste with Cmd/Ctrl+V onto multiple selected compatible clips. Intrinsic settings are replaced, added effects are appended, keyframes adapt to the destination duration, and installed plugin state is retained. Text fields keep their editing shortcuts.
- Fix the VST3 character ABI for Linux ARM64 builds. Includes the isolated VST2/VST3/AU host introduced in the previous source update.

## 0.12.0 preview.20261026.4

- Установленные аудиоэффекты VST 2.4, VST3 и Audio Units на macOS: сканирование
  стандартных и дополнительных папок в «Настройки → Плагины».
- Плагины доступны на аудиоклипах и в микшере, сгруппированы по производителю
  и категории; параметры, ключи и настройки сохраняются в проекте.
- Нативная обработка работает в отдельном процессе. Ошибка плагина останавливает
  экспорт и показывается пользователю; библиотека не загружается в редактор.
- Неудачный экспорт аудио или видео сохраняет предыдущий файл: новый результат
  записывается отдельно и заменяет его только после успешного завершения.
- В первой версии используется редактор параметров Smotri; фирменные окна
  плагинов, MIDI-инструменты и внешний sidechain пока не поддерживаются.
  Подробности: [аудиоплагины](docs/audio-plugins.md).

## 0.12.0 preview.20261026.3

- В активных текстовых полях выделение, копирование, вырезание, вставка,
  удаление и отмена работают с текстом, не затрагивая таймлайн. Исправлен
  обход фокуса через системное меню macOS; поддерживаются также Ctrl+A/C/X/V/Z.
- Проекты `.fcproj` открываются из Finder при запуске и в уже работающем
  редакторе. Несохранённые изменения защищены запросом сохранения;
  ошибка чтения нового файла сохраняет текущий проект.
- Для файлов проектов указана иконка Smotri. Формат проектов совместим
  с прежними файлами, конвертация не требуется.

## 0.12.0 preview.20261026.2

- В экспорте H.264 добавлены «Сжать до» и лимит в МБ рядом с оценкой размера.
- Битрейт видео и AAC рассчитывается по длительности; встроенный кодировщик
  выполняет два прохода без дополнительных программ.
- Размер готового файла проверяется, при превышении — до трёх попыток из
  исходной секвенции. Неудачный экспорт не заменяет предыдущий файл.
- Лимит означает «не больше», а не точный размер; сжатие может снижать качество.


## 0.12.0 preview.20261026.1

- Русский перевод настроек, панелей, эффектов и экспорта; проверка полноты каталога.
- Экспорт кадра предлагает свободное имя и сохраняет по Enter. Горячая клавиша
  по умолчанию: Option+Shift+E на macOS, Alt+Shift+E на Windows/Linux.
- Файлы из Finder можно бросать прямо на таймлайн, в том числе пустой:
  эпизод создаётся автоматически.
- Исправлена двойная вставка изображения из буфера обмена через меню macOS.

## 0.12.0 preview — 2026-10-26

В панели «Дубли» добавлен порог совпадения 50–100% (по умолчанию 80%). Поиск
игнорирует пунктуацию и регистр, допускает отличающиеся, пропущенные и добавленные
слова. Границы фраз определяются по паузам, а не точкам в расшифровке.
Порог можно пересчитать без повторной отправки аудио в ElevenLabs. В группе
показан минимальный процент сходства; удаление остаётся ручным, с предпросмотром и Undo.


## 0.12.0 preview — 2026-10-25

Добавлены панели «Графики», «Вертикальные видео» и SoundPad; собственные easing-пресеты;
эффект Shaker и команда «Эдит» в меню клипов; синхронизация аудио с размещением клипов
на свободных дорожках; импорт из буфера обмена с отдельной настройкой вставки на таймлайн.
Расширены команды Jarvis. Обновлены иконка macOS, русский интерфейс, сайт и документация.

Графики, синхронизация и создание Shorts поддерживают отмену. Исходная секвенция
Shorts используется как вложенная: её дальнейшие изменения отражаются в коротких версиях.
Модель анализирует текст, а оценка фрагментов не гарантирует вирусность.

Сборки предварительные. Редактор и CLI публикуются для macOS ARM64/Intel,
Windows x64/ARM64 и Linux x64/ARM64. WASM — модуль для разработки, не отдельный сайт.
Версия исходников записывается в BUILD.json и в сведения о приложении.

Компоненты Downloader не входят в эти архивы: ещё требуется полная упаковка
зависимостей и соответствующих исходников, а также перенос нормализации видео
с macOS на Windows/Linux. Это не установщики с полной поддержкой загрузчика.
macOS подписана локальной ad-hoc подписью, без нотарификации; Windows не подписана.
Проверяйте важные проекты на копиях. API-ключей автора в поставке нет.
