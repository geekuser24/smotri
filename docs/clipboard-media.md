# Вставка медиа из буфера обмена

Скопируйте изображение или GIF-файл, перейдите на таймлайн и нажмите **Cmd+V**
на macOS или **Ctrl+V** на Windows/Linux. Файл добавляется в проект и в позицию
курсора таймлайна на свободную незаблокированную дорожку. Если места нет,
создаётся новая дорожка. Импорт и размещение отменяются одним Undo.

**Настройки → Вставки → Буфер обмена → Добавлять из буфера обмена на таймлайн**
включено по умолчанию. Выключите для импорта только в проект. Эта настройка
независима от GIPHY и SoundPad. В панели «Проект» и без открытой секвенции
вставка всегда импортирует только в проект. Текстовые поля продолжают вставлять
текст; скопированные внутри редактора клипы продолжают вставляться как клипы.

Изображения из буфера сохраняются как PNG рядом с проектом (либо в выбранной
папке захвата). Для ещё не сохранённого проекта используется папка данных
редактора / Pasted Images. Файлы, скопированные в файловом менеджере, импортируются
по исходному пути, как при обычном импорте.

На macOS оригинальные данные GIF из pasteboard сохраняются без перекодирования,
с кадрами и временем анимации. Это работает, когда источник предоставляет GIF
(`com.compuserve.gif` / `image/gif`). Если браузер скопировал только растровый кадр,
вставится PNG: для анимации скопируйте скачанный GIF-файл из Finder/проводника.
Ссылки на страницы не скачиваются автоматически.

Предел исходного GIF — 64 MiB; декодированного RGBA — 256 MiB, сторона не более
32768 пикселей. Повреждённые размеры и содержимое дают ошибку без изменения проекта.

Проверка: 9 сценариев UI буфера (включая режим только проекта, GIF, Undo,
старый буфер после Copy/Cut и некорректные данные), отдельный сценарий настроек
OK/Cancel и 5 тестов импорта/свободных дорожек. Чтение исходного GIF на macOS
проверено на отдельном системном pasteboard, без изменения буфера пользователя.
